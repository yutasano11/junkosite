# ジュンコサン ホームページ デザイン案

静岡県焼津市の女性専用サロン「ジュンコサン」（https://junkosantikakuraga102.com/）のリニューアル用デザイン案です。
どちらも HTML / CSS / JavaScript だけで動く静的サイトで、`index.html` をブラウザで開けば表示できます。

| フォルダ | 内容 |
|---|---|
| [`mimosa/`](mimosa/) | ミモザ版。オーナーの好きなミモザと黄色を主役にしたデザイン。説明は [`mimosa/デザインの説明.md`](mimosa/デザインの説明.md) |
| [`kaizen/`](kaizen/) | 改善版。落ち着いたクリーム×茶色のデザイン。現行サイトの改善点33項目は [`kaizen/改善点一覧.md`](kaizen/改善点一覧.md) |

公開前に、赤い「※ご記入ください」マークの箇所（営業時間・定休日・駐車場・支払い方法・税込/税抜）を埋めてください。
