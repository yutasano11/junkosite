# ジュンコサン ミモザ版 デザインの説明

オーナーのジュンコさんがミモザ好きで、パーソナルカラーも黄色ということから、**「ミモザそのもの」をサイト全体のテーマ**にしたパターンです。
`index.html` をダブルクリックするとブラウザで見られます。

## 改善版（junkosan_改善版）との違い

| | 改善版 | ミモザ版 |
|---|---|---|
| 印象 | 落ち着いたクリーム色、黄色はアクセント程度 | 黄色が主役。明るく、元気で、春らしい |
| 配色 | クリーム × 茶色 × オレンジのボタン | ミモザの黄色 × 葉のグリーン × あたたかい白 |
| 文字 | 丸ゴシック | やわらかい手書き風の丸文字（Kiwi Maru）＋ 筆記体の英字 |
| 装飾 | ほぼなし | ミモザの枝のイラストが各所でふんわり揺れる |
| 写真 | 四角 | アーチ型・丸型にくり抜き、雑貨屋さんのような雰囲気に |
| メニュー | カード型 | 丸い写真＋点線でつないだ料金表（カフェのメニュー風） |
| お客様の声 | カード型 | ふきだし型＋ミモザの玉アイコン |

## ミモザらしさを出した工夫

- **ファーストビュー**：黄色一面の背景に、アーチ窓からミモザがのぞくデザイン。キャッチコピーは「ミモザのように、心までふわりとほどける時間を。」
- **ミモザの枝のイラスト**：画像ではなく軽いコード（SVG）で描いているので、表示速度に影響しません。ゆっくり揺れるアニメーション付き（動きを減らす設定の端末では止まります）。
- **ポイントの番号**：ミモザの丸い花をイメージした黄色いボール。
- **見出しの下の飾り**：ミモザの花が4つ並んだライン。
- **予約ボタン**：黄色の上でもはっきり見えるよう、ミモザの葉の深いグリーンに。
- **フッター**：グリーンの上にミモザのガーランド（花飾り）。
- **「— ジュンコ」の署名**：メッセージの最後に入れて、オーナーの人柄が伝わるように。

## 改善版から引き継いでいるもの

予約ボタンの配置、トップでの料金表示、スマホ下部の固定予約バー、検索対策（タイトル・説明文・お店情報）、画像の軽量化など、`junkosan_改善版\改善点一覧.md` の改善内容はすべてこちらにも入っています。

## 公開前に埋めてほしい箇所（赤い「要記入」マーク）

営業時間、定休日、駐車場、支払い方法、料金が税込か税抜か。

## さらに良くするなら

- **本物のミモザの写真**：今のファーストビューの写真は小さめ（540×360）なので、大きな写真があるとよりきれいです。サロンに飾っているミモザやリース、ジュンコさんがミモザを持っている写真などがあれば差し替えます。
- **ロゴ**：今のロゴは太陽のマークです。ミモザ版に合わせるなら、ミモザの枝を使ったロゴへの作り直しもおすすめです（今は仮でミモザの玉＋文字にしています）。
